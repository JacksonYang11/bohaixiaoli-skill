## 核心能力

这个 skill 解决以下问题：

- **选题精准化**：S/A/B/C 四级话题数据库 + 破圈五问——数学问题级别的选题筛选，不做小池子选题
- **标题工程化**：「为什么…」疑问式标题三大模板（验证爆款公式），口语词 + 知名IP + 反常识反差
- **去AI味**：自然叙事代替「第一第二第三」，设问、POV 切换、短段呼吸做章节衔接
- **争议驱动**：四层争议性嵌入模型，在史实正确前提下制造可讨论空间——给专业读者留「入场券」
- **对比分析**：中外对比矩阵 + 跨时代对比「三段跳」，表面相似深层不同的洞察型写作
- **算法适配**：六维算法信号模型（选题/标题/开头/完读/转发/标签），相乘关系一维瘸腿全篇白做
- **公众号排版**：手机屏幕节奏、加粗关键句、结尾金句可截图转发、下集预告代替感谢阅读

## 诚实边界

- 这是**写作风格 + 传播策略** Skill，不能替你查史料
- 基于 2026 年 5 月前作品 + 7 篇公众号推文对比数据，无法预测作者未来的新技法
- 「去AI味」的终点是你的判断力，skill 只给方向和自检
- 争议性机制的目的是制造讨论空间，不是鼓励说假话——所有「裂缝」都必须是真实存在的学术讨论空间
- 话题数据库基于公众认知度分析，不构成内容质量判断
