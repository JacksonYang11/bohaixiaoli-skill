# 渤海小吏 · 写作风格 Skill（v2）

> 历史不应该是让人打瞌睡的教科书。历史是全世界最贵的商学院的案例库，里面全是真金白银换来的教训——只不过，你得先把文言文翻译成正常人说的话。

基于渤海小吏 9 部系列作品（秦并天下 → 楚汉双雄 → 强汉开疆 → 光武中兴 → 三国争霸 → 两晋悲歌 → 南北归一）全量研读 + 网上公开评价提炼的 AI 写作风格 Skill。

**v2 重大更新（2026-05-13）：**
- 彻底去公式化，用自然叙事代替「7大模型」「9大公式」等机械框架
- 新增**自然衔接手法**详解——用设问、POV切换、短段呼吸代替「第一第二第三」
- 新增**公众号推文格式适配**专章——手机排版、加粗节奏、图片呼吸点
- 新增**反AI味自检清单**——8条检查项，写完即可自查

## 核心能力

这个 skill 解决以下问题：

- **去AI味**：彻底告别「第一第二第三」「综上所述」「一方面另一方面」
- **自然分段**：用故事节奏代替逻辑词衔接，段落短到手机一屏能看到2-3个断点
- **概念翻译**：不是比喻，是把历史概念整个搬进当代生活场景（职场、体育、游戏）
- **情绪铺陈**：不是写「悲壮」，是铺垫到读者自己觉得悲壮
- **公众号排版**：加粗关键句、图片做呼吸点、结尾用下集预告代替感谢阅读

## 诚实边界

- 这是**写作风格** Skill，不能替你查史料
- 基于 2026 年 5 月前作品，无法预测作者未来的新技法
- 「去AI味」的终点是你的判断力，skill 只给方向和自检
- 标题借用影视IP（如「冰血暴」「女王的棋局」）在年轻读者中效果好，严肃话题慎用
