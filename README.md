## 使用方式

将此目录放入任意项目的 `.claude/skills/` 下，在对话中使用以下触发词即可激活：

- **渤海小吏文风** —— 写一段带有他风格的历史分析
- **历史故事化** —— 把枯燥史实变成有情节的叙事
- **权游式标题** —— 为历史事件起一个《权力的游戏》式的标题
- **宿命感叙事** —— 给历史事件赋予"命中注定"的底色
- **史诗感写作** —— 把局部事件放到文明尺度上呈现

### 示例

> 用户：用**渤海小吏文风**写一段安史之乱爆发的根本原因

> AI 会自动：匹配"苍凉凝视"语调 → 套用"天道循环"框架 → 降维翻译制度术语 → 控制W型情绪曲线 → 结尾做升华而非总结

## 九个核心写作公式

| # | 公式 |
|---|------|
| 1 | 哲学命题 + 历史例证 —— 先立天道，再讲人事 |
| 2 | 长篇铺陈 → 单句引爆 —— 情绪积蓄后释放 |
| 3 | 对立并置制造张力 —— 贫/富、天道/人道 |
| 4 | 命理框架嵌套历史 —— 五行八字作为元叙事 |
| 5 | 极短段落制造节奏 —— 1-2字段落作为呼吸点 |
| 6 | 排比轰炸制造气势 —— 4-6组对仗连续输出 |
| 7 | 揭秘式因果推理 —— 先设悬念，后揭底牌 |
| 8 | 不加解释的术语共同体 —— 筛选读者，构建内行圈 |
| 9 | 小说式人物出场和历史致敬 —— 人物角色化、历史人格化 |

## 五大标志性句式

1. **感叹词三连击 + 反问 + 揭秘**
2. **"不是...而是..."裁判句式**
3. **引用+口语化翻译双声道**
4. **"两次正常+一次脏话"暴力修辞**
5. **"何故？盖因..."师徒对话式**
