# 渤海小吏式幽默 · 写作技法

> "你觉得你在看历史，其实你在看当代。"

## 框架概览

渤海小吏的幽默不是偶尔插入笑点的"调料"，而是一套**系统的叙事语言体系**。核心思路一句话：**用21世纪中文互联网的语感讲帝王将相的博弈。**

12类技法按功能分为四个层次：

| 层次 | 功能 | 包含技法 |
|------|------|---------|
| **第一层：翻译层** | 把古代用语"翻译"成现代词汇 | ①现代外号 ②职场语系 ③商业语系 ④娱乐圈语系 ⑤互联网语系 |
| **第二层：介入层** | 作者跳出叙事直接与读者对话 | ⑥"咱也不知道" ⑦括号弹幕 ⑧反讽体 |
| **第三层：语感层** | 口语化、粗粝化的语言节奏 | ⑨粗粝口语 ⑩"套路"叙事 ⑪"这就好比"类比 |
| **第四层：结构层** | 用现代叙事框架重述整段历史 | ⑫长段故事重述 |

使用时一般按 **一层起步、二层调味、三层贯穿、四层点睛** 的原则。

---

## 技法详解

### 第一层：翻译层 —— 把古代"翻译"成当代

**核心原理**：把古代的人名、职位、事件用21世纪中文互联网词汇重新命名，制造"认知穿越"的幽默感。关键是选词要准确——外号不能瞎起，要跟这个人真实的特点对上。

#### ① 现代外号体系

给人名加上现代职业/身份后缀，形成"古人+现代头衔"的混搭：

| 外号格式 | 效果 | 示例 |
|---------|------|------|
| 姓+现代职务 | 降维打击，把大人物变普通人 | 刘主任（刘邦）、萧主任（萧何）、曹老板（曹操） |
| 姓+绰号 | 增加江湖气 | 刘老三（刘邦）、韩半仙（韩信） |
| 职能类比 | 制造荒诞的跨界感 | 大汉CIA局长（陈平）、战国首席诈骗犯（张仪） |
| 艺人/网红化 | 把政治人物娱乐化 | 传销奇才苏秦讲师、摆拍仁主（苻坚） |

**使用规则**：
- 一个角色一篇里固定1-2个外号，不要换太多
- 外号要跟这个人的核心特点形成反差或精准点破
- 第一次出现时可以在括号里补一句解释，此后直接用外号

**反例**：乱起外号、跟人物无关的外号、过于低俗的外号（不在外号中直接使用脏字）

#### ② 职场语系

把古代官职行为"翻译"成现代职场语言：

| 古代概念 | 翻译为 |
|---------|--------|
| 出仕/入朝 | 去XX那上班 |
| 辞官/隐居 | 养老退二线 |
| 朝堂争议 | 开会 |
| 罢官/免职 | 裁员/优化 |
| 赏赐/俸禄 | 发工资/绩效工资 |
| 权臣受托孤 | 当了XX的CEO |
| 给下属许诺 | 画饼 |
| 选边站队 | 在XX赛道下注 |
| 世代传承 | 家族规划/产品投放 |

**典型句式**：
- "XX去曹操那上班的第一天"
- "按时打卡上下班，取消所有娱乐活动闭目养神"
- "奋斗过程中的同志是最好画饼与利用的"

**使用规则**：只用于叙事层面的比喻，不要在严肃分析时用（比如不要在分析制度优劣时说"周朝的封建制就是个烂KPI"）。

#### ③ 商业语系

政治博弈"翻译"成商业/投资行为：

| 古代概念 | 翻译为 |
|---------|--------|
| 资助某人 | 天使投资/第一轮融资 |
| 外交游说 | 国际诈骗/推销梦想方案 |
| 政治联盟 | 入股/合伙人 |
| 背叛盟友 | 跳单/撕毁合同 |
| 放弃某政策 | 止损/及时止损 |
| 获取政治合法性 | 蹭天命流量 |

**典型句式**：
- "苏秦这个穷小子空手套白狼的获得了第一笔天使投资"
- "霍光在投资亏损后极高明的迅速止损了"
- "这就好比你有一个亿，你会把两千万交给谁去理财？一个是资深经纪人，一个是表现不错的年轻交易员"

**使用规则**：投资类比适合用在"做选择"、"利益博弈"的场景。风险类决策（押注、赌命）要慎用轻浮的商业词汇。

#### ④ 娱乐圈语系

用综艺/影视/体育词汇类比：

| 词汇 | 适用场景 |
|------|---------|
| 剧本 | 形容有预谋的政治操作 |
| 流量/蹭流量 | 形容争夺关注度的行为 |
| 票房 | 形容某项政策的群众反响 |
| 出道 | 形容人物首次登上历史舞台 |
| MVP/冠军 | 形容某战役的最高功绩者 |
| 季后赛/常规赛 | 区分大战役和小摩擦 |
| IP | 形容某人的历史影响力 |
| 导演 | 形容幕后策划 |
| 分公司 | 形容势力扩张 |

**典型句式**：
- "这次他兴大兵而来，摆明了要蹭去年张辽的流量"
- "儒家道德楷模，全国流量超巨"
- "我司马宣王那一骑绝尘的风情，在朱自清先生的散文进入课本之前一直是牢牢占据'背影'这个IP的"

**使用规则**：用大家耳熟能详的梗（NBA、西游记、金庸），不要用过于小众的圈子梗。梗要新但仍被大众所知。

#### ⑤ 互联网语系

用最近十年的网络新词：

| 词汇 | 适用场景 |
|------|---------|
| 内卷 | 形容内部竞争消耗 |
| 版本 | 形容历史的阶段性变化 |
| 服务器换服 | 形容势力转移/重生 |
| 韭菜/割韭菜 | 形容被收割的底层 |
| 签到的 | 形容只出工不出力的人 |
| 骚操作 | 形容出其不意但有效的举动 |
| 拼爹 | 形容门阀世袭的本质 |

**使用规则**：这是需要最谨慎的一类。只用那些"已经沉淀下来"的网络词（如内卷、套路），不用太新的词（如"绝绝子""巴比Q"这类三个月后就过时的）。宁可少用，不要用错。

**典型句式**：
- "方方面面，都像是一个二十岁版本的刘裕换了服务器后重开在了北境"
- "江南土豪们一比较后发现...都比不上一大家子内卷了20多年的司马家政策好"
- "还没看明白八戒沙僧就是俩签到的？"

### 第二层：介入层 —— 作者"入镜"与读者对话

**核心原理**：打破"客观叙述"的第四面墙，作者直接跳进来吐槽、提问、自嘲。制造"说书人"的现场感。

#### ⑥ "咱也不知道"系列

假装疑惑实则吐槽的经典句式：

**模板**：
- "咱也不知道XXX是咋想的" —— 吐槽某人决策
- "咱也不知道XXX跟谁学的" —— 吐槽某人能力
- "咱也不敢说，咱也不敢问，反正很凑巧" —— 暗示有猫腻
- "咱也不知道你嘀咕个啥" —— 吐槽某人优柔寡断

**适用时机**：遇到历史记载缺失、历史人物做出匪夷所思的决策、存在"刚好凑巧"的可疑事件时。

**使用规则**：一篇用1-3次，不要超过5次。多了就显得贫。

#### ⑦ 括号弹幕

在正文中插入括号，里面是作者的白话评论，类似视频弹幕：

**类型**：
- 补充吐槽：*（你听听，整个就一大明白）*
- 跳出警示：*（题外话：此做法极损阴德，万不可做！）*
- 生活化解释：*（上岁数了喜欢鸟也正常）*
- 补充说明：*（韩国就不提了，那点体量不吃劲了）*

**使用规则**：括号内容必须短（10字以内最佳，超过20字考虑放正文）。括号里要用纯口语，越像弹幕越好。

#### ⑧ 反讽体

假装站在对立面说话，实则表达相反意思：

**经典案例（冰血暴篇赞司马迁）**：
> "你司马迁写的都是私货呀！喷将军们是最见不得私货的，简直恶心。你喜欢项羽就喜欢呗！怎么能胆大包天的给项羽和老刘搁到一个历史地位来了个《本纪》！...你特么也配写历史！满眼都是私货！太辣眼了！恶心！恶心呐！呸！"

**使用规则**：反讽体需要完整的情绪堆叠，不能只是一句。至少3-4句递进，最后反转。适合用于批评某种荒谬观点，或赞扬一个被低估的人物。

### 第三层：语感层 —— 口语化、粗粝化的语言节奏

**核心原理**：文章读起来像"朋友在饭桌上跟你吹牛逼"，而不是"老师在讲台上给你上课"。

#### ⑨ 粗粝口语

高频使用的口语词库：

| 词 | 用法 | 力度 |
|----|------|------|
| 完蛋 | 形容失败/崩溃 | 中 |
| 特么/他妈的 | 加重语气 | 强 |
| 扯淡 | 否定某种说法 | 中 |
| 臭不要脸 | 批评不道德行为 | 强 |
| 瘪犊子 | 形容不成器的后代 | 中 |
| 神经病 | 形容反复无常/暴虐的君主 | 弱（当幽默标签用） |
| 骚操作 | 形容反常规但有效的做法 | 弱 |
| 得瑟 | 形容得意忘形 | 弱 |
| 不靠谱 | 形容不稳定的决策/联盟 | 中 |

**使用节奏**：脏话类（特么/臭不要脸）每3000字不超过3次。轻量级口语（扯淡/不靠谱/完蛋）可以高频使用。整体语感要做到"敢说但不脏"。

#### ⑩ "套路"叙事

把一切政治博弈解读为"套路"，这是渤海小吏最核心的叙事框架：

**典型句式**：
- "我去说一下王莽后面的打法套路...后面全是这套路，我就不总说了，说多了恶心"
- "一个将军，对不同的阶层受众必须要完完全全两个套路"
- "从没有一个套路能够应对万事万物，能够包打天下"

**使用规则**："套路"这个词本身体现了一种"我把权力游戏的底牌翻给你看"的姿态。适合用来总结归纳某人重复使用的操作模式，或揭露某种政治操作的本质。"套路"叙事必须要有对读者说"你看穿了吗"的居高临下感，但不能变成阴谋论——要有史料支撑。

#### ⑪ "这就好比"类比

用现代生活场景解释古代逻辑，制造"原来如此"的顿悟感：

**类比素材库**：
- 投资理财（一个亿交给谁管）
- 职场晋升（跳槽/竞聘/站队）
- 家庭关系（分家产/婆媳矛盾/兄弟争执）
- 体育比赛（逆转/绝杀/换战术）
- 物理/工程原理（炸药试验室/飞机迫降）
- 游戏机制（换服务器/开新服/练级）

**使用规则**：类比必须精准，不能为了好笑而强行比。一个好的类比如："皇权的交接过程就好比研制炸药的试验室"——既形象又准确。

### 第四层：结构层 —— 现代叙事框架重述

**核心原理**：挑一段历史，用现代故事的叙事框架完整重述，加入心理描写、动机揣测、现代价值观评判。这是12类技法中最重的，也是最出彩的。

#### ⑫ 长段故事重述

**经典案例**：
- 孙悟空取经解构（用《西游记》隐喻南北朝政治，约3000字）
- 苏秦传销传奇（把纵横家写成现代销售大师，约500字）
- 司马家族赛道上岸指南（用互联网创业思维写门阀崛起）

**写作步骤**：
1. 选一个历史片段——有戏剧性、有人物、有冲突
2. 选一个现代叙事框架——职场/商战/体育/电影
3. 把历史人物"装"进现代角色——谁是CEO、谁是投资人、谁是竞品
4. 全程用现代语言叙述，只保留关键史实锚点
5. 结尾用一两句拉回历史视角，制造"你以为我在讲段子，其实我在讲历史"的效果

**使用规则**：这是大招，一篇写200-500字即可（整篇重述的那种3000字级只有特别篇才用）。不要滥用，一篇用一次足够了。

## 使用指南

### 场景适配

| 写作场景 | 推荐技法组合 | 幽默强度 |
|---------|------------|---------|
| 历史分析文章 | ①外号 + ②职场 + ⑥咱也不知道 + ⑩套路 | 中等 |
| 人物评传 | ①外号 + ②职场 + ⑦括号弹幕 + ⑨粗粝口语 | 中等 |
| 事件复盘 | ③商业 + ④娱乐圈 + ⑪类比 | 偏轻 |
| 制度/趋势分析 | ⑤互联网 + ⑩套路 + ⑪类比 | 偏轻 |
| 轻松番外/花絮 | ⑧反讽 + ⑨粗粝口语 + ⑫故事重述 | 偏重 |
| 公众号推文 | 全技法灵活组合 | 中高 |
| 开场/结尾 | ⑦括号弹幕 + ⑨粗粝口语 + ⑪类比 | 偏轻 |

### 强度控制

| 强度 | 定义 | 示例组合 |
|------|------|---------|
| 轻微 | 偶尔点缀，保持专业感 | ①+⑦（偶尔） |
| 中等 | 有节奏地穿插，有幽默但不抢内容 | ①+②+⑥+⑩ |
| 较重 | 幽默成为重要组成部分 | 全部一层技法 + ⑥⑦⑨ |
| 满配 | 段子手模式，适合娱乐向内容 | 所有技法火力全开 |

### 节奏控制

- 严肃内容段落之间用一句括号弹幕"破冰"
- 每800-1000字至少有一次幽默干预
- 连续三段的纯严肃内容后必须插入一个活跃点
- 最幽默的段落放在文章1/3处（读者最容易放弃的地方）

## 反模式（绝不做的事）

| # | 反模式 | 说明 / 替代做法 |
|---|--------|----------------|
| 1 | **堆砌所有技法** | 一篇文章用3-5类技法就够，12类全上场会变成段子汇编，不是文章 |
| 2 | **用过于小众的梗** | 圈内梗读者看不懂，等于白用。只用大众熟知的NBA、西游记、金庸这类 |
| 3 | **脏话溢出** | "特么"每3000字不超过3次。可以"糙"但不能"脏" |
| 4 | **强行类比** | 类比必须精准。如果想不到好的类比，宁可不用，不要瞎比 |
| 5 | **幽默掩盖知识错误** | 幽默是佐料，历史准确性是主食。不能为了搞笑编造史实 |
| 6 | **在所有话题上强行幽默** | 涉及大规模死亡、民族悲剧、宗教敏感话题时，幽默必须克制或回避 |
| 7 | **滥用"咱也不知道"** | 一篇用1-3次，超过5次读者会觉得你在水字数 |
| 8 | **外号不统一** | 同一个人物在不同篇目中的外号尽量保持一致，避免读者迷惑 |

## 完整示例

### 示例：一段没有幽默的严肃历史文本，如何用本技法改造

**原文（假设）**：
> 公元208年，曹操已统一北方，任丞相。他征召司马懿入朝任职，司马懿最初以风痹病为由推辞。曹操派人暗中观察，发现司马懿装病。后曹操再次征召，态度强硬，司马懿被迫就职。此后司马懿在曹魏历任重要职位，逐渐积累政治资本。

**改造后（运用①②⑥⑨技法）**：
> 208年，曹老板已经当丞相了，再次调司马懿来上班。
>
> 关于司马懿是咋来打工的，《晋书》是这么说的：曹老板让他来上班，他认为汉室国运已衰，不想屈尊，借口风痹病不能起居。
>
> 这段历史，基本上古往今来的看法是——编的。
>
> 而且编得很不走心。司马师小朋友在这一年都出生了。不是不能起居嘛！风痹病患者咋把媳妇肚子搞大了，真厉害。（咱也不知道史官写这段的时候脸不脸红）
>
> 我相信司马宣王这么谨慎的人，对阵诸葛丞相贴身紧逼不下脚的主，怎么可能在媳妇身上刹不住车！

### 示例：一段"套路"叙事

**原文（假设）**：
> 王莽篡位的过程体现了其精心的政治操作。他先指使党羽上奏为自己请封，然后磕头哭泣坚决推辞，感动太后。如此反复多次，最终"勉强"接受禅让。

**改造后（⑩套路叙事）**：
